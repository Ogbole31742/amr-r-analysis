# AMR R Analysis

R-based mathematics, statistics, and antimicrobial resistance analysis.

## About

This project documents my practical learning and application of R, statistics, data analysis, and Git/GitHub, with a focus on microbiology and antimicrobial resistance (AMR).

The project is being developed as a reproducible computational portfolio alongside my background in microbiology, molecular biology, genomics, and AMR research.

## Objectives

- Learn R programming systematically
- Strengthen mathematical and statistical foundations
- Learn reproducible data analysis
- Apply statistical concepts to microbiological data
- Analyse antimicrobial resistance data
- Develop data visualization skills
- Practice Git and GitHub workflows
- Build reproducible computational research projects
